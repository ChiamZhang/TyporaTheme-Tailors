1. 经典日落天色渐变与色彩层级体系 (Headings)

Tailors 汲取经典日落渐变与多层级色彩徽标设计，层次生动丰富，让长文排版结构自然明晰：

三级标题 · 珊瑚暖橘指示条 (Heading 3)

三级标题左侧配有珊瑚暖橘专属强调指示条与 3 阶暖橘点阵徽标，字阶舒适饱满。

四级标题 · 暮色玫红发光圆点 (Heading 4)

四级标题带有暮色玫红实心微光圆点与 4 阶玫红点阵，段落切分醒目灵动（8px 等宽规格）。

五级标题 · 暮光罗兰空心环圈 (Heading 5)

五级标题带有暮光罗兰空心环圈与 5 阶罗兰紫点阵，结构严谨层次细腻（8px 等宽规格）。

六级标题 · 深邃天青极简短横杠 (Heading 6)

六级标题搭配深邃天青等宽短横杠与 6 阶深天青点阵，支持深度技术笔记与复杂文档的整洁编排（8px 等宽规格）。

3. 内联文本与微拟物交互 (Inline Styles & Neumorphism)

文字排版完整支持所有 Markdown 行内语法，各元素之间拥有和谐统一的视觉层级与细腻触感：

  • 支持 粗体强调 (Bold)、斜体字形 (Italic) 以及具有深蓝暗夜内凹凹槽质感的 行内代码 (Inline Code)；
  • 提供离底 3.5px 的清新晴空蓝 荧光下划线 (Underline) 与 温润高亮标记 (Highlight)；
  • 包含删除线 Strikethrough 与精致渐变展开超链接 Interactive Link；
  • 通过 HTML <var> 标签可直接生成新拟态立体微拟物胶囊：微拟物标签、凸起药丸徽标（悬停微凹）。

6. 快速安装与使用指南 (Installation)

  1. 点击页面右上角或下方按钮下载主题包：下载 TyporaTheme-Tailors (ZIP)
  2. 在 Typora 中打开主题文件夹：
    • macOS: Typora → 偏好设置 → 外观 → 打开主题文件夹
    • Windows / Linux: 文件 → 偏好设置 → 外观 → 打开主题文件夹
  3. 解压压缩包，将 tailors.css 与 tailors 字体文件夹拷贝到主题目录中。
  4. 重启 Typora，在顶部菜单 “主题” 中选择 Tailors 即可尽享优雅写作。

💡 平台兼容性提示：本主题在 macOS 上深度设计与测试，已完成跨平台排版优化，全面兼容 Windows 与 Linux 系统。
